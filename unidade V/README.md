# Unidade V — Projeto CRISP-DM

Nesta unidade, apresentamos uma análise descritiva da produção hospitalar e dos leitos cadastrados no Distrito Federal, usando dados agregados do SIH/SUS e do CNES e a metodologia CRISP-DM.

O projeto reúne a documentação, os arquivos de dados, os scripts Python, o notebook executado, os resultados e os gráficos em PNG.
